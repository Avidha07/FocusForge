
# FocusForge

FocusForge is a customizable productivity and career-growth tracker designed to help users build consistency, manage recurring tasks, track study progress, and stay focused during job preparation journeys.

## Features

- Daily, weekly, monthly, and yearly goals
- Recurring task management
- Pomodoro timer
- Study tracking
- Analytics dashboard
- Streak tracking
- Custom categories

## Tech Stack

### Frontend
- React
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL

## Future Features

- Heatmap analytics
- AI productivity suggestions
- Calendar integration
- Smart reports
